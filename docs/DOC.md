# DailyDots ドキュメント

このファイルは、README より少しだけ詳しく実装の意図をまとめた補助資料です。

## 画面構成

- Home: 最新の journal を確認し、すぐに新規入力できる
- My Journals: 保存済み一覧を確認し、編集・削除できる
- Add New Journal: 日付を指定して新規作成または更新できる

## 主要な流れ

1. Home で最新の記録を確認する
2. JournalForm から日付、気分、本文を入力する
3. useJournalEntries を通して保存する
4. journalStorageService が localStorage に書き込む
5. My Journals で保存結果を一覧から確認する

## 入力ルール

- 日付は YYYY-MM-DD 形式を前提にしている
- 気分は固定の 5 種類から選ぶ
- 本文は必須で、短すぎる入力は弾く
- 本文は最大 2000 文字まで入力可能で、入力欄下にリアルタイムの文字数カウンターを表示する
- 保存時に本文の前後空白は除去する

## 実装メモ

- 同じ日付の journal は 1 件に制限している
- 並び順は日付の降順で、同日なら更新日時を使って安定化している
- データの保存・取得・削除はサービス層に寄せている
- 画面側は state の更新だけに集中している
